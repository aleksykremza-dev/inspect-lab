# Security and scope

## Scope
All evaluations in this repository target **only the author's own systems**: a local model and an isolated copy of the
author's own support bot. No third-party or production systems were tested.

## What is not published
- The attack base used in the runs (derived from published datasets; see `kremzapay_eval/data/SOURCES.md` for sources and licenses).
- The bot's knowledge base. It is restricted and belongs to the bot project, which has its own license.
- Run logs and local databases (they may contain test inputs).

## Reporting
If you find a problem with this code or its results, please open an issue.
